# Daniel Amadi Portfolio

[![Netlify Status](https://api.netlify.com/api/v1/badges/46648482-644c-4c80-bafb-872057e51b6b/deploy-status)](https://app.netlify.com/sites/next-dev-starter/deploys)

This is a [Next.js](https://nextjs.org/) portfolio app using TypeScript, Tailwind CSS, Material UI, and pnpm.

## Getting Started

First, run the development server:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `pages/index.tsx`. The page auto-updates as you edit the file.

## Scripts

- `pnpm dev` starts the local development server.
- `pnpm build` creates a production build and generates the sitemap.
- `pnpm typecheck` runs TypeScript.
- `pnpm lint` runs ESLint.

Netlify builds the site with `pnpm build`.
